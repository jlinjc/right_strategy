## 績效數字(最大的信任問題)
頁面上的數字是不同條件混在一起用,沒有標註:
- 美股今天頁「17.7%/−48.6%」= 單押、沒有信用哨。**現行設定(等權 + RiskTarget + 信用哨)= 17.3%/−34.2%**(重跑一致)。
- 台股 19.3% = 沒有信用哨。**現行設定 = 22.4%/−18.2%**。
- 決策清單「原版 22.9%」標籤有誤導;原版 RiskTarget 是 13.2%。台股 13.2→19.3 的進步主要來自取消 RiskTarget,等權主要提升 Sharpe(1.05→1.26)。
- 「多賺約 3.8pp」在 repo 找不到計算來源(負責人粗估約 4.6pp)。
- 頁面上的績效都沒有包含黃燈規則,也沒有包含「隔日執行」的落差。
